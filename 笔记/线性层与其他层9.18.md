## 一、全局地图

```
输入图片
   ↓
[卷积] [激活] [池化]      ← 前半场：负责"看"（提取特征）
   ↓ （重复几轮）
   ↓  ← 到这里数据还是三维 (通道, 高, 宽)
[展平 Flatten]            ← 形状转换的桥梁
   ↓
[线性层 Linear] [激活]     ← 后半场：负责"判断"（下结论）
   ↓
[线性层 Linear]
   ↓
十个类别的分数
```

**一句话定位：前半场产出"证据"，后半场根据证据"判决"。**

## 二、为什么需要线性层

### 2.1 卷积层只报告，不总结

卷积层是**模式匹配器**：扫一遍图，把"这里有竖边""这里有黄黑条纹"记成数字。但它**不会综合**——每个卷积核只管自己那一小块。

### 2.2 线性层 = 医生看体检报告

> 化验单上几十项指标，**报告单本身不会告诉你"有没有病"**。是医生看着这些指标，结合经验做出判断。

- **卷积层 = 化验科**：把原始信息加工成一项项指标
- **线性层 = 医生**：综合所有指标下结论

"综合判断"最朴素的数学实现：**给每项指标配一个"重视程度"，然后加权求和。**

### 2.3 障碍：形状对不上

| | 长什么样 |
|---|---|
| 卷积层吐出来的 | `(64, 4, 4)` —— 三维 |
| 线性层想吃的 | `(1024,)` —— 一维向量 |

所以中间必须有个**展平**动作。

## 三、Flatten：把三维摊成一维

### 3.1 动作

```
(一个通道)             展平后
┌───┬───┬───┐
│ a │ b │ c │
├───┼───┼───┤          [a, b, c, d, e, f, g, h, i]
│ d │ e │ f │    →
├───┼───┼───┤
│ g │ h │ i │
└───┴───┴───┘
```

顺序 = **行优先**：一行一行往下读；多通道时，第 0 张图全读完再读第 1 张。

```
64 张 4×4  →  64 × 4 × 4 = 1024 个数字
```

### 3.2 三种写法

```python
x = torch.randn(64, 3, 4, 4)

y = x.flatten(1)                       # ① Tensor 方法（土堆常用）
y = torch.flatten(x, start_dim=1)      # ② torch 函数
y = torch.nn.Flatten()(x)              # ③ 当作层用
print(y.shape)                         # torch.Size([64, 48])
```

### 3.3 ★ 那个 `1` 是最关键的坑

```
x.shape = (64,   3,  4,  4)
            ↑     └──┬──┘
         batch     这部分摊平 → 48
        不能动！
结果：(64, 48)
```

| 写法 | 默认从哪维开始 | 对 4D 的结果 |
|---|---|---|
| `torch.flatten(x)` | **0**（全摊） | `(3072,)` ❌ batch 没了 |
| `nn.Flatten()` | **1**（保住 batch） | `(64, 48)` ✅ |

> **口诀：展平永远从第 1 维开始，因为第 0 维是 batch。习惯写 `x.flatten(1)`。**

## 四、nn.Linear

### 4.1 本质：加权求和

**一个输出数字怎么来？**

```
out₀ = x₁·w₀₁ + x₂·w₀₂ + … + x₁₀₂₄·w₀,₁₀₂₄ + b₀
```

> **比喻：10 个评委。** 每个评委看同一份 1024 项证据，但各有侧重（评委 0 特别看重条纹，评委 3 特别看重颜色）。最后每人给一个分。

**一个 Linear 层 = 一排并联的探测器。** `out_features` 的真正含义：**用多少把不同方向的尺子去量同一份输入。**

### 4.2 参数

```python
layer = nn.Linear(in_features=1024, out_features=10, bias=True)
```

| 参数 | 含义 | 怎么定 |
|---|---|---|
| `in_features` | 进去几个数 | **必须和上层输出对上**，手动算 |
| `out_features` | 出来几个数 | 自己设计，最后一层 = 类别数 |
| `bias` | 要不要 `+b` | 默认 `True` |

### 4.3 weight 的形状：`(out, in)`

```python
l = nn.Linear(4, 3)
print(l.weight.shape)   # torch.Size([3, 4])
print(l.bias.shape)     # torch.Size([3])

# weight = [[w₀₁, w₀₂, w₀₃, w₀₄],   ← 第 0 个评委的 4 个权重
#           [w₁₁, w₁₂, w₁₃, w₁₄],   ← 第 1 个评委的 4 个权重
#           [w₂₁, w₂₂, w₂₃, w₂₄]]   ← 第 2 个评委的 4 个权重
```

**参数量公式：`in × out + out`**（上例 4×3+3 = 15）

### 4.4 ★ 只动最后一维

```
(..., in_features)  →  (..., out_features)
```

```python
l = nn.Linear(4, 3)
l(torch.randn(64, 4)).shape        # (64, 3)
l(torch.randn(64, 10, 4)).shape    # (64, 10, 3)   ← 前面维度原样保留
```

**原因**：PyTorch 把前面所有维度都当成"打包的行"。**你永远不用操心 batch。**

**硬性要求**：最后一维必须正好等于 `in_features`，否则：

```
RuntimeError: mat1 and mat2 shapes cannot be multiplied (64x400 and 1024x10)
```

## 五、经典网络串讲（形状推导是核心练习）

```python
model = nn.Sequential(
    nn.Conv2d(3, 32, 5, padding=2),
    nn.MaxPool2d(2),
    nn.Conv2d(32, 32, 5, padding=2),
    nn.MaxPool2d(2),
    nn.Conv2d(32, 64, 5, padding=2),
    nn.MaxPool2d(2),
    nn.Flatten(),
    nn.Linear(1024, 64),
    nn.Linear(64, 10),
)
```

| 步骤 | 操作 | 形状 |
|---|---|---|
| 输入 | — | `(64, 3, 32, 32)` |
| ① | Conv2d(3→32, k=5, p=2) | `(64, 32, 32, 32)` |
| ② | MaxPool2d(2) | `(64, 32, 16, 16)` |
| ③ | Conv2d(32→32, k=5, p=2) | `(64, 32, 16, 16)` |
| ④ | MaxPool2d(2) | `(64, 32, 8, 8)` |
| ⑤ | Conv2d(32→64, k=5, p=2) | `(64, 64, 8, 8)` |
| ⑥ | MaxPool2d(2) | `(64, 64, 4, 4)` |
| ⑦ | **Flatten** | `(64, 1024)` ← `64×4×4` |
| ⑧ | **Linear(1024, 64)** | `(64, 64)` |
| ⑨ | **Linear(64, 10)** | `(64, 10)` |

> ★ **填 `in_features` 的唯一方法**：手动把 Flatten 之前的三个数乘起来。

### 为什么中间要插一层 64？

- **直接 1024→10**：10 个评委直接看 1024 项原始证据
- **1024→64→10**：先请 64 个"初级分析员"归纳出中间结论，10 个最终评委只看这 64 个中间结论

**中间层能组合出原始特征里不存在的概念**（"黄色 + 有毛 + 有触角"同时出现的程度）。

⚠️ **但中间必须夹激活函数**，否则线性叠线性还是一层：

```python
nn.Linear(1024, 64),
nn.ReLU(),              # ★ 加了这个，64 个分析员才算真正独立
nn.Linear(64, 10),
```

**最后一层后面不加 ReLU** —— 要的是原始分数（有正有负），ReLU 会把负数压成 0。

## 六、其他层地图

| 层 | 干什么 | 重要度 |
|---|---|---|
| **Flatten** | 把多维摊成一维 | ★★★ 必会 |
| **BatchNorm** | 把每批数据"拉回标准尺度" | ★★ |
| **Dropout** | 训练时随机"关掉"一部分神经元 | ★★ |
| **Embedding** | 把整数编号变成向量 | ★★ |
| **RNN/LSTM/GRU** | 处理有顺序的数据 | ★ 知道即可 |
| **Transformer** | 现在的当红炸子鸡 | ★ 知道即可 |

### BatchNorm

**一句话：把每层数据重新拉回均值 0、方差 1 的尺度。**

> 接力赛比喻：第一棒把棒扔到 500 米外，第二棒要跑 500 米才追上……数值范围不断漂移，后面的层很难学。

```
数据进来 → 减均值、除标准差 → 标准尺度 → 再乘一个可学习系数 γ、加可学习偏移 β
```

最后那步很关键：**归一化太狠会丢信息，给它一个"自我调节"的旋钮。**

效果：训练更快更稳，可以用更大的学习率。

### Dropout

**训练时随机"关掉"一部分神经元。**

> 团队里某人特别靠谱，其他人都依赖他 → 他一请假就崩。Dropout 就是**每次开会随机让一部分人请假**，逼每个人独立掌握技能。

两个要点：
1. **只在训练时开，测试时关** → 这就是 `model.train()` / `model.eval()` 存在的原因
2. 缩放由 PyTorch 自动处理（inverted dropout），不用管

### Embedding

**把整数编号查表变成向量。**

```python
emb = nn.Embedding(10000, 128)   # 词表 10000 词，每词 128 维向量
emb(torch.tensor([1, 5, 88])).shape   # torch.Size([3, 128])
```

妙处：**向量是学出来的**——训练后意思相近的词向量会靠近。本质是**可学习的查找表**。

## 七、深入问答（本次重点）

### 7.1 为什么必须展平？

**表层**：`nn.Linear` 存的是矩阵 `W (out, in)`，算 `y = W @ x`。矩阵乘法要求 `x` 必须是**一维向量**。

**深层**：理论上可以让 Linear 吃 3D（存四维权重），但**收益为零**——因为每个输出都要用到**全部**输入，"谁是通道/高/宽"对计算毫无影响。所以干脆让你显式摊平。

**展平丢了什么？** ⚠️ **信息一点没丢**（是双射，可 reshape 回去）。**丢的是"结构"**：

- 线性层不知道索引 17 和 18 原来是相邻像素
- 后果：要学的参数变多（每对相邻关系得单独学）、平移不变性丢了

**彩蛋**：展平后的线性层 ≡ **用整张图那么大的卷积核卷一次**

```python
nn.Sequential(nn.Flatten(), nn.Linear(1024, 10))
≡  nn.Conv2d(64, 10, kernel_size=4)    # 输出 (N,10,1,1)，squeeze 后一样
```

> **记法：全连接 = 感受野覆盖整张图的卷积。**

---

### 7.2 线性层和激活层，是不是在做同一件事？

**它们是一个神经元的两半。**

```
输入 → [加权求和 Σwx] → [超过阈值?] → 输出
            ↑                ↑
        线性层的事        激活函数的事
```

| | 线性层 | 激活函数 |
|---|---|---|
| 干什么 | **算分**（加权求和） | **决定这个分够不够格传下去** |
| 作用于 | **跨元素**：一次看 1024 个数 | **逐元素**：一次只看 1 个数 |
| 比喻 | 称重员 | 门卫 |
| 有参数吗 | 有 | 无（固定规则） |

`ReLU(w·x + b)` 这一整个表达式，才是"一个判断"。

**为什么必须分成两步？** 因为两者正交：

| 缺了谁 | 后果 |
|---|---|
| 缺激活函数 | 多层退化成一层，网络再深也只会画直线 |
| 缺线性层 | 只剩逐元素 ReLU，**信息永不混合**，学不出任何组合概念 |

> **一句话：线性层负责"混合"，激活函数负责"弯折"。缺一个，网络废一半。**

---

### 7.3 一个数字怎么反映多个特征？

**纠正措辞：那数字不"反映"多个特征，它"被多个结论以不同权重使用"。**

> 一个学生数学考 85（只有一个含义）。但：
> - 上理科班：数学权重 **0.8**
> - 上文科班：数学权重 **0.2**
> - 进体育队：数学权重 **0.0**
>
> **同一个 85，在不同评价体系里被赋予不同的重要性。**

输入的第 5 个数 `x₅`，出现在全部 10 个输出里，每个输出给它配的权重不同（`w₀,₅` / `w₁,₅` / …）。

**反过来更重要：一个结论也不是一个数字决定的。**

> "蜜蜂"这个概念，是**一整片数字共同的分布模式** —— 就像一个像素不能构成一张脸。

这叫**分布式表示**。所以网络里是**多对多**的。

**这就是"全连接"三个字的字面含义：每一个输入都连到每一个输出。**

验证实验：

```python
layer = nn.Linear(4, 3)
x  = torch.tensor([[1., 2., 3., 4.]])
x2 = torch.tensor([[1., 2., 100., 4.]])
print(layer(x2) - layer(x))   # 一个输入的变化，让所有输出都变了，但变化量各不相同
```

### 7.4 bias 到底是什么

#### 身份一：阈值（`-b`）

```
ReLU(w·x + b) 放行条件：w·x > -b
                              ↑
                          阈值 = -b
```

#### 身份二：让分界线能平移的唯一手段 ★

**有 bias**（两个输入）：
```
w₁x₁ + w₂x₂ + b > 0   →   w₁x₁ + w₂x₂ > -b
分界线可以放在任意位置
```

**没有 bias（b = 0）**：
```
w₁x₁ + w₂x₂ > 0
分界线被钉死在"必须穿过原点"
```

```
   有 bias              没有 bias
   x₂                   x₂
    │  ╱                 │  ╱
    │ ╱  ← 可以在这      │ ╱  ← 只能绕原点转
    │╱                  │╱
────┼──── x₁        ────┼──── x₁
   ╱                   ╱
```

**没有 bias，模型能画的边界就少了整整一个自由度。**

想实现 `x₁ + x₂ > 5`：
- 有 bias：`w=(1,1), b=-5` ✅
- 无 bias：找不到 `w'` 使 `w'·x > 0` 等价于 `x₁+x₂ > 5` ❌（因为 `w'·x>0` 永远过原点）

> **缩放权重改变的是"响应有多陡"，不是"门槛在哪"。这是两个独立的自由度。**

#### 身份三：先验 / 默认倾向

**bias = 当所有证据都为 0 时，这个评委给出的默认分。**

训练集 90% 是蚂蚁时，网络会学到：
```
蚂蚁评委：b = +2.0   ← 底分高
蜜蜂评委：b = -1.0   ← 底分低
```
**即使输入一片模糊，网络也默认猜蚂蚁** —— 这在该数据集上是统计正确的（闭着眼猜有 90% 正确率）。

| | 作用 |
|---|---|
| **weight** | 根据**证据**调整判断 |
| **bias** | **证据为零**时的默认判断 |

#### ★ 名字"偏见"的由来

英文就是同一个词 **`bias`**：

| 领域 | 含义 |
|---|---|
| 统计学 | 估计量的期望与真值之间的**系统性差距**（有偏估计） |
| 神经网络 | 一个与输入无关的**系统性偏移** |
| 日常中文 | 偏见 |

**共同内核：与输入无关的、系统性的偏移。**

- **最后一层的 bias** = **class prior（类别先验）**，直接对应"对类别的偏见"，可被人理解
- **中间层的 bias** 不对应任何人类概念，只是"让分界线不必过原点"的数学自由度

> ★ **bias 让网络"聪明地利用先验"，同时也让网络"忠实地继承数据集的缺陷"。**
> 训练集真实 → 偏见是有用的先验；训练集有偏 → 偏见是有害的固化。

#### 什么时候可以不要 bias

**后面紧跟 BatchNorm 时**（工程上最常见）：

```python
nn.Conv2d(64, 128, 3, bias=False),   # ← 故意砍掉
nn.BatchNorm2d(128),
```

因为 BN 第一步就是减均值：`(x + b) - (mean + b) = x - mean` —— **b 被抵消了，白加**。平移的工作由 BN 自己的 `β` 接管。

#### 纠正一个流传很广的说法

| 说法 | 准确吗 |
|---|---|
| ~~"bias 初始化为 0"~~ | ⚠️ 早期框架/部分教材如此，**现代 PyTorch 不是** |
| "bias 只是可有可无的常数项" | ❌ 它是唯一能让分界线平移的旋钮 |

### 7.5 一个神经元到底学到了什么

#### 一维演示（手设 `w=2, b=-1`）

| 输入 x | 0.0 | 0.2 | **0.5** | 0.6 | 1.0 | 2.0 |
|---|---|---|---|---|---|---|
| z = 2x−1 | −1.0 | −0.6 | **0.0** | 0.2 | 1.0 | 3.0 |
| ReLU(z) | 0 | 0 | **0** | **0.2** | **1.0** | **3.0** |

**分界线在 x = 0.5**（即 `-b/w`）。

#### ★ 输出的是"超出多少"，不是"有/没有"

| | x=0.5 | x=0.6 | x=1.0 | x=2.0 |
|---|---|---|---|---|
| 阶跃函数（老式） | 1 | 1 | 1 | 1 |
| **ReLU（现在）** | 0 | **0.2** | **1.0** | **3.0** |

**ReLU 保留了"这个特征有多强"的连续信息。** 下游因此能区分"刚刚达标"和"非常典型"。

> 这是"深度网络能学出细腻东西"的微观基础：**每层传递"强度"，而不是"有/无"。**

#### 多维：`w` 是方向，`-b/‖w‖` 是门槛

`w·x` 的几何含义 = **把 x 投影到 w 方向上，量投影有多长**。

```
① w 决定：往哪个方向看
② w·x 算：输入在这个方向上有多"像"
③ 超过门槛 -b/‖w‖ 就放行
```

> **一个神经元 = 一把尺子。`w` 决定尺子朝哪放，`-b/‖w‖` 决定刻度从哪开始。**

#### ★ 权重的"方向"和"长度"是两回事

`w=(1,1), b=-5` 与 `w=(2,2), b=-10` 的**放行位置完全一样**，只是输出幅度差 2 倍。

| | 决定什么 |
|---|---|
| **w 的方向** | 探测**哪种模式** ← 这才是"学到了什么" |
| **w 的长度** | 输出**放大几倍** ← 下游可轻松抵消 |
| **b** | 门槛的位置 |

> **推论：权重的"方向"有意义，"长度"基本无意义。**
> 判断"某特征重要吗"看权重绝对值 —— **没用**。只有**同一层内不同权重的相对大小**才有意义。
> （这也再次解释了为什么 `Conv → BN` 时能砍掉 bias：BN 把"长度"这个自由度完全接管了。）

### 7.6 初始化：为什么 weight 随机

#### 事实（在 `torch_learn` 环境实测）

```python
torch.manual_seed(0)
l = nn.Linear(4, 3)
print(l.bias)     # tensor([-0.4777, -0.3311, -0.2061])   ← 不是 0！
```

PyTorch 源码 `reset_parameters`：

```python
init.kaiming_uniform_(self.weight, a=math.sqrt(5))   # → 均匀分布 [-1/√in, 1/√in]
bound = 1 / math.sqrt(fan_in)
init.uniform_(self.bias, -bound, bound)              # ← bias 也是小随机
```

验证：`nn.Linear(1024, 64)` 的权重范围 = `[-0.03125, +0.03125]`，正好 `1/√1024`。

#### 实测：四种初始化训同一个网络

网络 `Linear(10,64) → ReLU → Linear(64,1)`，同样 300 步：

| 初始化 | 最终 loss | 64 个神经元之间的差异 | 发生了什么 |
|---|---|---|---|
| **随机（标准）** | **0.0484** | **0.4319** | ✅ 正常收敛 |
| 全 0 | 5.2251 | **0.000000** | 💀 完全没动 |
| 第一层全 0.5（第二层随机） | 1.7206 | 0.227463 | ⚠️ **居然分化了**，但差 35 倍 |
| 整个网络全 0.5 | 5.2083 | **0.000002** | 💀 完全没动 |

> ⚠️ **修正一个常见说法**：「常数初始化会让神经元永远一样」**只在"整个网络都常数"时成立**。

#### 为什么整个网络常数会死透

```
∂L/∂wᵢ = (∂L/∂y) · vᵢ · ReLU'(zᵢ) · x
                    ↑
          「下一层有多重视第 i 个神经元」
```

- **全网常数** → 所有 `vᵢ` 相同 → 梯度完全相同 → **永远捆在一起**
- **单层常数、下层随机** → `vᵢ` 不同 → **会被拽开**（但很慢）

#### 为什么全 0 是真正的死局

```python
z = torch.tensor(0.0, requires_grad=True)
torch.relu(z).backward()
print(z.grad)        # tensor(0.)     ← PyTorch 里 ReLU'(0) = 0
```

**整条链乘上 0，梯度永远为 0，权重永远不动。** 这叫 **dead ReLU**（神经元死亡），训练中也会自发出现。

#### 为什么"会分化"还是不行

loss 差 35 倍，三个原因：
1. **起点浪费**：前期 64 个神经元干同样的活
2. **分化是被动拽开的**，不是主动探索，方向没针对性
3. **梯度信号"抱团"**，打破很慢

> **★ 正确结论：随机初始化的目的不是"防止卡死"（那是全 0 的问题），而是"让 64 个神经元从第一天起就各有所长"。**

#### 为什么范围是 `1/√in` —— 尺度守恒（实测）

| 输入宽度 `in` | 权重边界 `1/√in` | 输出 std |
|---|---|---|
| 4 | 0.50000 | 0.6373 |
| 64 | 0.12500 | 0.5837 |
| **1024** | **0.03125** | **0.5800** |

**不管输入是 4 维还是 1024 维，输出大小始终稳定在 0.58 左右。**

没有这个 `/√in`，1024 个数相加会让量级按 `√1024 = 32` 倍层层增长 → 第 n 层后爆炸。

> **口诀：输入越宽，每个权重就压得越小，总和始终稳定。** 这是能训练深层网络的前提。

#### 初始化是唯一的"注入人类知识"的接口

| 例子 | 做法 | 意图 |
|---|---|---|
| LSTM 遗忘门 | bias 初始化成 **1**（默认 0.5 → 0.73） | 开局默认"记住"，因为 LSTM 存在的意义就是长依赖 |
| ResNet 残差块 | 最后一层 BN 的 `γ` 初始化为 **0** | 开局是恒等映射（什么都不做），再慢慢学 |

## 八、Linear 的参数会学习吗？

**会，机制和卷积层完全一样。**

```python
l = nn.Linear(4, 3)
print(l.weight.requires_grad, l.bias.requires_grad)   # True True
```

### ★ 对优化器来说，所有层毫无区别

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
```

`model.parameters()` 是个**扁平列表**，里面既有卷积核也有线性矩阵。优化器一视同仁：

```
p ← p − lr × p.grad
```

> 这是 `nn.Module` 最漂亮的地方。**也正是"层忘了挂 `self.`"这个坑那么隐蔽的原因** —— 没挂上就进不了账本，优化器看不见，**永远不更新，还不报错**。

### 唯一的区别：梯度**怎么算**

#### 线性层：梯度直接等于输入

```python
l = nn.Linear(2, 1)
# 手设 w=[1,1], b=0
x = torch.tensor([[3., 4.]])
l(x).sum().backward()
print(l.weight.grad)   # [[3., 4.]]   ← 就等于输入 x！
print(l.bias.grad)     # [1.]         ← 恒为 1
```

因为 `y = w·x`，对 `w` 求导就是 `x`。**bias 的梯度恒为 1 —— 它永远"有人推"。**

#### 卷积层：同一个核复用多次，梯度要**累加**

```python
c = nn.Conv2d(1, 1, 2, bias=False)   # 核 = [[1,1],[1,1]]
img = [[1, 2],
       [3, 4]]
c(img).sum().backward()
print(c.weight.grad)   # [[1., 2.], [3., 4.]]   ← 就是图像那块区域
```

核扫过的**每个位置**都产生一份梯度，最后**全部加起来**。

| | 梯度是什么 |
|---|---|
| **Linear** | 每个权重只用一次 → 梯度 = 它对应的那个输入 |
| **Conv** | 同一个核复用 N 次 → 梯度 = N 个位置贡献的**累加** |

> **这就是"参数共享"在梯度上的体现**：共享的代价是梯度要合并，好处是规律能用在所有位置。

## 九、多通道被"平等"展平，合适吗？

### 9.1 先纠错：它**不是**"平等对待"

```
flatten 后:  [c0p0, ..., c0p15, c1p0, ..., c1p15, c2p0, ...]
               ↓               ↓               ↓
权重:        w[:, 0]         w[:, 16]        w[:, 32]      ← 完全不同的参数
```

**同一空间位置、不同通道的两个像素，用的是完全不同的权重。** 线性层**有能力**区分对待。

"平等"只体现在：**它们被同一个公式（加权求和）处理。** 但**公式相同 ≠ 参数相同**。

**线性层是一张白纸 —— 什么都不知道，全靠数据教。**

### 9.2 真正的损失

| | 线性层 | 卷积层 |
|---|---|---|
| 知道"通道 0 和 1 是同类"吗？ | ❌ | ✅（同一个核扫所有通道） |
| 知道"相邻像素相关"吗？ | ❌ | ✅（核只看局部） |
| 知道"模式出现在哪都是同一个模式"吗？ | ❌ | ✅（核在空间上共享） |

**卷积层带着先验出生，线性层是白纸。** 代价：参数爆炸 + 学得慢。

### 9.3 ★ 关键：在哪一层用

```
输入的 3 通道 (R/G/B)：  ❌ 不同质
   → 三种不同的物理测量
   → 直接 flatten 喂 Linear = 灾难（30730 个参数，无平移不变性）

经过 3 层卷积后的 64 通道： ✅ 同质
   → 不是 64 种不同的东西
   → 是 64 个"学出来的特征检测器"的响应图
   → 语义都是同一句："某某模式的强度分布"
```

#### 同质性的真正来源

> **通道 i 和通道 j 是用同一个公式生产的 —— "对上一层所有通道做一次加权组合"。唯一的区别只是那套权重不同。**
> **它们是同一个函数的不同参数化，所以天然同类。**

（R/G/B 不同质，因为它们是三种不同的物理传感器测出来的。）

#### ★ 卷积层的隐藏功劳

> **卷积层不只是"提取特征"，它还把"异质的原始测量"整理成了"同质的特征响应" —— 整理成线性层能消化的样子。**

### 9.4 判断标准

> **问自己："这一叠通道，在语义上是不是'同一类东西'？"**
> - 是 → 展平给 Linear 没问题
> - 不是 → 展平会丢掉"它们是不同维度"这个信息

### 9.5 ⚠️ Flatten + Linear 对通道是"半尊重"的

| | 尊重吗 |
|---|---|
| 给每个通道不同权重？ | ✅ 尊重 |
| 承认"一个通道是一张完整的图"？ | ❌ **不尊重** —— 当成 1024 个互相独立的数 |

### 9.6 想"跨通道混合但保留空间结构" → 用 **1×1 卷积**

```python
nn.Conv2d(64, 128, kernel_size=1)      # (N,64,H,W) → (N,128,H,W)
```

**含义：在每个空间位置上，独立地做一次 `Linear(64, 128)`。**

| 做法 | 空间上共享？ | 通道上混合？ | 等价于 |
|---|---|---|---|
| `Flatten + Linear` | ❌ 每位置独立权重 | ✅ | **卷积核 = 整张图** |
| `Conv2d(kernel_size=1)` | ✅ 全图共享 | ✅ | **每个位置套一个 Linear** |
| `Conv2d(kernel_size=k)` | ✅ 全图共享 | ✅ | 局部 + 共享（真卷积） |

> ResNet 的 bottleneck 就是靠 1×1 卷积做降维/升维的。

## 十、常见报错

| 报错 | 原因 | 修法 |
|---|---|---|
| `mat1 and mat2 shapes cannot be multiplied` | `in_features` 和上层输出对不上 | 手动重算 Flatten 前的形状 |

| 训不动、loss 不降 | 层没挂 `self.` | 全改 `self.xxx = 层(...)` |

## 十一、一句话总结

> **线性层是一排"方向探测器"。每个探测器有一个看的方向（`w`）、一个门槛（`-b/‖w‖`），超过了就把"超出多少"报给下一层。**
>
> - **Flatten** 是桥梁，把 `(N,C,H,W)` 摊成 `(N, C×H×W)`，**永远从第 1 维开始**
> - **Linear** 的 `in_features` 必须手算（Flatten 前三个数相乘），weight 形状 `(out, in)`，只动最后一维
> - **bias** 不是装饰：它是唯一能让分界线平移的旋钮；最后一层的 bias 就是**对数据集分布的先验**
> - **weight 必须随机**：不是"防卡死"（那是全 0 的问题），而是"让 64 个神经元从第一天起就各有所长"
> - **通道同质之后**才能展平喂 Linear —— 而"把异质测量整理成同质响应"正是卷积层的隐藏功劳
